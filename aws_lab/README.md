# Terraform Learning Path — Class 1404

Welcome to the Terraform module! This directory contains three progressive projects that take you from zero to deploying real infrastructure on AWS.

---

## Projects

| # | Directory | Focus | Difficulty |
|---|-----------|-------|------------|
| 1 | [`01-terraform-install`](./01-terraform-install/) | Install Terraform & run your first commands | ⭐ Beginner |
| 2 | [`02-terraform-aws-sample`](./02-terraform-aws-sample/) | Deploy a simple AWS resource using Terraform's built-in workflow | ⭐⭐ Intermediate |
| 3 | [`03-terraform-ec2-full`](./03-terraform-ec2-full/) | Provision a full EC2 project with user data, security groups, and networking | ⭐⭐⭐ Advanced |

---

## Prerequisites

- An AWS account (free tier is fine)
- AWS CLI installed and configured (`aws configure`)
- A terminal (macOS, Linux, or WSL on Windows)

---

## How to Use

Work through the projects **in order**. Each one builds on the concepts from the previous one:

1. **Start with Project 1** — Install Terraform and verify it works locally.
2. **Move to Project 2** — Use Terraform to create a basic AWS resource using the standard init → plan → apply workflow.
3. **Finish with Project 3** — Build a complete, production-style EC2 deployment with networking, security, and automation.

---

*Each project has its own README with full instructions. Good luck! 🚀*
